02Font licence

F37 Aria, for the wordmark

The wordmark is set in F37 Aria Regular. Using a typeface in a logo needs F37's Logo licence; their cheaper Basic licence explicitly excludes logos. It is priced per style and by company size, and paid once.

Our pick

Logo licence, Startup tier, Regular only: £400 one-off, about A$762. The site already shows the wordmark as an image rather than live text, which is what the Logo licence requires, so no Web licence is needed. If Actualise has more than five people including contractors, the Small tier (£1,200) applies.

The site is plain HTML, CSS and JavaScript, with no shop. What matters: importing it as it is, adding script plugins (the front desk, analytics, a form service), and editing it with Claude, which works by changing the files in a Git repository; the host then publishes each change automatically.

Our pick

Cloudflare Pages, free. Connect the site's GitHub repository once; after that, every change Claude makes is published automatically, with a preview link to check first. Plugins are just script tags in the page, which Claude can add or change. The runner-up is Netlify Personal (about A$154 a year) if built-in forms matter more than cost.

08Notes

Assumptions and caveats

  • The Logo licence covers one version of one logo. A second lockup (for example a stacked version) may need a second licence, and if the wordmark's letters have been altered from the font, F37 has to approve it. Worth confirming with F37 before buying.
  • F37 prices by employees, including contractors across the group. Declaring too few costs a £300 admin fee plus the difference.
  • Prices exclude GST and VAT. F37 calculates tax at checkout, and overseas purchases may carry card fees.
  • AUD figures are converted at the rates above and rounded; recheck before buying, as rates and promotions change.
  • Netlify's free plan isn't recommended: each update uses credits, and the site is paused once they run out.
  • Hello Gubby's price is indicative only. It comes from a sample quote, and the currency isn't stated.
  • Formspree's pricing page shows conflicting figures, and Plausible's and Fathom's yearly prices are worked out from their monthly prices.
