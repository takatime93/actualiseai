# Actualise AI — site concept

Two pages, built by `source/site.py` in the identity project (edit that script, not these files):

- `index.html`: the reworked actualiseai.com.au homepage, using the current site's copy. Images are placeholders for now.
- `identity/`: the Actus brand identity.

The header switches between three colour concepts (Ink, Cobalt, Loam) and light or dark mode. The choice is remembered in the browser and carries across both pages. Old identity links such as `/#colour` forward to `identity/#colour`.
